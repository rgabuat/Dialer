# Documentation Hub

This directory centralizes application documentation so operational guides, module references, and diagrams are kept outside the runtime code directories.

## Structure

```text
docs/
|-- README.md                 # Documentation index
|-- diagrams/
|   |-- modules.mmd           # High-level module map
|   `-- modules/              # Per-module Mermaid diagrams
`-- modules/                  # Per-module functional documentation
```
