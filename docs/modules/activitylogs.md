# Activity Logs Module

## Purpose

This module provides the UI for reviewing activity history recorded by the application.

## Diagram

See [docs/diagrams/modules/activitylogs.mmd](docs/diagrams/modules/activitylogs.mmd).

## Source Location

- `app/Livewire/Activitylogs/`

## Components

- `ActivitylogsIndex`: lists and surfaces recorded activity entries.

## Related Domain Objects

- `ActivityLog`
- `AuditLog`

## Notes

- This module is read-oriented and supports operational visibility into system actions.
