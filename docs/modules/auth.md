# Auth Module

## Summary

- Area: Access Control
- Purpose: handle sign-in, registration, and password recovery.
- Source: `app/Livewire/Auth/`
- Diagram: [docs/diagrams/modules/auth.mmd](docs/diagrams/modules/auth.mmd)

## Components

- `Login`: authenticates an existing user.
- `Register`: creates a new account when registration is enabled.
- `ForgotPassword`: starts password reset flow.
- `ResetPassword`: completes password reset.

## Related Types

- `User`
